# Screenwriting Project

## What this is
A screenwriting tool with a Node.js/Express backend and Claude AI integration. Features a screenplay editor with formatting support (scene headings, action, dialogue, character, parenthetical, transitions), AI-powered proofreading via the Anthropic API with streaming responses, and DOCX export in proper screenplay format.

## Standard Rules

These rules apply to every project I start. They are inherited
automatically by each new project's CLAUDE.md.

### Code style
- Prefer clarity over cleverness
- Keep functions short and named for what they do
- Comment intent, not mechanics

### File and folder conventions
- Source files in /src
- Tests next to the file they test
- Configuration at the project root

### Project organisation
- All project folders live in ~/claude-workspace/
- Never create project folders directly in the home directory

### Working with me
- Plan before writing code
- Show me what will change before changing it
- When something is unclear, ask rather than assume
